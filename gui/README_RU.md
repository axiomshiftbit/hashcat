# Hashcat Desktop

Интерфейс на C++17 и Qt 6 для Windows 10/11 x64 и Linux x64.
Русский и английский языки переключаются в правом верхнем углу.

Конструктор команд, проверки параметров и парсер типов хешей взяты из
[rgroesslinger/hashcat-gui](https://github.com/rgroesslinger/hashcat-gui).
Оформление панели, график скорости, карточки устройств и каталог конвертеров
адаптированы из [Hashcat-Reactor](https://github.com/jjsvs/Hashcat-Reactor).
Точные версии и сведения об авторах находятся в THIRD_PARTY.md.

## Запуск

**Windows:** распакуйте архив целиком и запустите `hashcat-desktop.exe`.
Каталоги `hashcat/` и `tools/` должны оставаться рядом с программой. Комплект
включает Hashcat, Qt, библиотеки MSVC, hcxtools, John Jumbo, Python, Perl и
зависимости конвертеров. WSL и отдельная установка Python/Perl не требуются.
Для работы на GPU установите вычислительный драйвер производителя видеокарты.

**Linux:** архив рассчитан на Ubuntu 24.04 / Debian 13 и более новые системы.
Установите `qt6-base-dev`, `hashcat`, `hcxtools` и вычислительный драйвер.
Для работы на CPU подходят `pocl-opencl-icd` и `ocl-icd-libopencl1`.
Запустите `./hashcat-desktop`. На других дистрибутивах соберите программу из исходников.

## Работа

1. Выберите исполняемый файл Hashcat вверху окна и нажмите «Загрузить режимы».
2. Откройте форму новой задачи: выберите тип хеша, режим, входной файл и словарь
   либо маску. Добавьте задачу в очередь и запустите её.
3. На рабочем экране доступны прогресс, скорость, журнал, результаты, пауза,
   продолжение, остановка на контрольной точке и восстановление сессии.
4. Раздел «Команды» позволяет передать любые параметры установленной версии
   Hashcat, в том числе отсутствующие в форме. Введите один аргумент на строку
   либо JSON-массив строк. Пробелы внутри аргумента сохраняются; оболочка не запускается.
5. В разделе «Справка» находятся руководство и поиск по полной справке движка.

Для восстановления нужны прежние входные файлы и сохранённый restore-файл.
Удаление строки очереди сохраняет файлы задачи. После перезапуска приложения
прерванные задачи автоматически не возобновляются. Профили сохраняют настройки
формы. Каталог данных можно выбрать параметром `--data-dir ПУТЬ`. Повреждённый,
недоступный или созданный неподдерживаемой версией файл рабочей области
не перезаписывается: сохранение отключается до восстановления файла или выбора
другого каталога данных.

Формы охватывают десять режимов: 0, 1, 3, 4, 5, 6, 7, 8, 9 и 12.
Для 4/5/8/12 нужен Hashcat 8. Словари и правила выполняются в порядке отмеченных
строк; неотмеченные строки тоже сохраняются в профиле. Настройки PCFG, таблиц и
генераторов находятся на соответствующих вкладках расширенных параметров.
В режиме 12 маска содержит один `?w` и, при втором словаре, один `?q` после него.
Наращивание длины для этого режима недоступно.

Таблица показывает до 2000 результатов и до 8 МиБ данных. Экспорт сохраняет весь
файл в формате `хеш:hex`; hex сохраняет произвольные байты пароля.

## Конвертер

Конвертация выполняется локально через официальные `hcxpcapngtool` и `hcxhash2cap`.
Поддержаны PCAP, PCAPNG, CAP, gzip, HCCAPX, HCCAP и старый PMKID/16800.
Выходные режимы: WPA/WPA2 (22000), EAP-MD5 (4800), LEAP/MSCHAPv2 (5500),
TACACS+ (16100). Это включает форматы захватов
[официального онлайн-конвертера](https://hashcat.net/cap2hashcat/).

На Linux установите `hcxtools`. Windows-комплект автоматически использует
вложенную сборку hcxtools с переносимой средой Cygwin. Сборку для Windows
собирает и проверяет этот проект; upstream hcxtools Windows не поддерживает.
При желании можно выбрать hcxtools в основном дистрибутиве WSL.
Исходные захваты не отправляются на сервер. Существующий выходной файл не заменяется.

Вторая вкладка конвертера использует каталог Reactor из 78 утилит, включая ZIP,
RAR, 7z, PDF, Office и KeePass. В Windows нужные экстракторы
[John Jumbo](https://github.com/openwall/john) и зависимости уже включены.
Оставьте поле интерпретатора пустым для автоматического выбора. В Linux
установите John Jumbo и зависимости нужных форматов, затем укажите каталог run.
Аргументы передаются
по одному на строку; исходный файл добавляется последним аргументом.
Приложение убирает метаданные имени файла из записей `$...$` и проверяет результат
через `Hashcat --identify`. Сохранение и импорт доступны только после распознавания.
При нескольких подходящих типах выберите нужный вручную. Ошибка, отмена, пустой
или несовместимый вывод не создают файл результата. Наличие в каталоге не означает,
что все 78 форматов поддерживаются Hashcat: у каждой утилиты свои зависимости и
ограничения версий. Бинарный вывод и форматы без записей `$...$` требуют отдельной
подготовки вне этого конвертера.

## Сборка и проверки

Нужны CMake 3.21+, компилятор C++17 и Qt 6.4+ с Widgets, Concurrent и Test.

```sh
cmake -S gui -B gui/build -DCMAKE_BUILD_TYPE=Release
cmake --build gui/build --config Release --parallel 2
ctest --test-dir gui/build -C Release --output-on-failure
```

В Windows задайте `CMAKE_PREFIX_PATH` для Qt MSVC x64 и добавьте его `bin` в PATH.
Переменная `REAL_HASHCAT` включает проверки с настоящим движком на синтетических
данных. GitHub Actions собирает обе платформы. Проверки CPU не подтверждают
совместимость со всеми моделями GPU и версиями драйверов.

Объединённый интерфейс распространяется под GPL-3.0-or-later; см. LICENSE и
THIRD_PARTY.md. Отдельный движок Hashcat сохраняет MIT. В оба архива включён
`HashcatDesktop-source.tar.gz` с исходниками интерфейса и инструкциями сборки.
Qt подключён динамически и сохраняет
свои лицензии. В Windows-архив включены исходники Qt Base 6.12.0, лицензии,
уведомления сторонних компонентов, параметры сборки и SBOM. Библиотеки Qt можно
пересобрать и заменить, в том числе для отладки изменений.

Версии, контрольные суммы и исходники конвертеров и их зависимостей находятся
в `licenses/`. Скрипты сборки переносимого комплекта находятся в `gui/packaging/`.
